# Scripts Overview

## `walrus/`
- `store-blob.sh` – Store a file as a Walrus blob.
- `read-blob.sh` – Read blob contents into a file.
- `extend-blob.sh` – Extend blob storage duration.
- `delete-blob.sh` – Delete a blob.

## `setup/`
- `fund-account.sh` – Exchange testnet SUI for WAL and show balances.

All scripts default to the `testnet` context. Set `WALRUS_CONTEXT` to override.
